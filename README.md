TechPoint

¡Bienvenido a TechPoint!

TechPoint es una aplicación web de autoservicio orientada a la venta de productos tecnológicos y accesorios. Permite a los clientes explorar el catálogo, seleccionar productos, gestionar su carrito y confirmar compras, obteniendo un ticket de compra en formato PDF.

Además, cuenta con un panel de administración para gestionar productos, imágenes, usuarios y ventas.

Tecnologías utilizadas: Node.js, Express, MySQL, Sequelize, JavaScript, HTML, CSS, EJS, Multer y Puppeteer.
